# Library Management System

## Overview
A full-stack web application built with Django for managing library operations including book management, user authentication, and borrowing system.

## Features
- 📚 Book Management — add, edit, delete, and search books
- 👤 User Authentication — signup, login, and role-based access (librarian vs user)
- 🔄 Borrow & Return — full book borrowing and return tracking
- 🔍 Search — search books by title, author, or category
- 🎨 Responsive UI — custom CSS styled web interface

## Tech Stack
- Python, Django
- SQLite Database
- HTML, CSS
- Django ORM & Migrations

## Installation & Setup
1. Clone the repository:
   git clone https://github.com/KritikaGupta15/Library-Management-System.git

2. Install Django:
   pip install django

3. Run migrations:
   python manage.py migrate

4. Start the server:
   python manage.py runserver

5. Visit: http://127.0.0.1:8000
